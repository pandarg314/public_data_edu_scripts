# 4 ESO - juegos eliminatorios GeoGebra

Filosofia comun: grupos de 2 a 4. GeoGebra sortea un reto, muestra opciones cerradas y comprueba la casilla elegida. Acierto: siguen jugando. Fallo: eliminados.

Plantilla base: banco de retos, sorteo aleatorio, 3-6 opciones, una respuesta valida, feedback inmediato y boton de nuevo reto.

- `T1_numeros_reales`: sortea numeros, intervalos o rectas; el grupo elige clasificacion o representacion correcta.
- `T2_polinomios_y_fracciones_algebraicas`: sortea expresion, grafica o factorizacion; el grupo elige raices, dominio, factor o forma equivalente.
- `T3_ecuaciones_sistemas_e_inecuaciones`: sortea ecuacion, sistema o region; el grupo elige solucion, punto de corte o intervalo valido.
- `T5_trigonometria`: sortea triangulo o angulo; el grupo elige razon trigonometrica, lado, angulo o identidad correcta.
- `T6_geometria_analitica`: sortea puntos y rectas; el grupo elige pendiente, ecuacion, distancia, punto medio o posicion relativa.
- `T7_y_T8_funciones`: sortea una grafica; el grupo elige familia, expresion o transformacion correcta.

Contexto actual: los `.ggb` ya creados estan en `T7_y_T8_funciones/01_reconocer_por_la_grafica/` y sirven como modelo del juego de funciones.
