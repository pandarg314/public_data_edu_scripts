# Recetario PAU Matematicas

## Sistemas segun el determinante

Para un sistema cuadrado `A X = b`:

- Si `det(A) != 0`=> SCD 
- Si `det(A) = 0`: Si `rg(A)=rg(A|b)` => SCI; si no, SI

## Rango por menores

- Menor orden `n` `!=0` => `rg(A)>=n`
- Menor orden `n` `=0` => no concluye
- Todos los menores orden `n` `=0` => `rg(A)<n`

## Paridad de una funcion

- `f(-x)=f(x)` => par
- `f(-x)=-f(x)` => impar
- Si no, ni par ni impar

## Limites

- Sustituir primero; si sale numero, fin
- `0/0` => factorizar y simplificar; con raices, conjugado
- `inf/inf` racional => comparar grados: `<` da `0`, `=` da cociente coef., `>` da `+/-inf`
- `inf-inf` => comun denominador o conjugado
- `0*inf` => pasar a cociente
- `a/0` (`a!=0`) => laterales y signos: `+/-inf`
- `x->+inf`: `sqrt(x^2)=x`; `x->-inf`: `sqrt(x^2)=-x`
- Potencias raras (`1^inf`, `0^0`, `inf^0`) => tomar logaritmos
- Crecimiento: `e^x` gana a potencias; potencias ganan a `ln x`
- Basico: `lim sin(x)/x = 1` cuando `x->0`

## Recta tangente

- A `f` en `x=a`: `y=f(a)+f'(a)(x-a)`
